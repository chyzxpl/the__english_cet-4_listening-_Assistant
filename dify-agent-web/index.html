排错指引
  1. Dify 未启动：docker compose up -d，确认能打开 http://localhost。
  2. Token 填错：在 Dify 应用 →「访问 API / WebApp」里复制 WebApp 链接。
  3. iframe 被拦截：检查 Dify 的 nginx / CSP frame-ancestors 白名单。
  4. 端口写全：例如 http://localhost:8088，不要只写域名。
