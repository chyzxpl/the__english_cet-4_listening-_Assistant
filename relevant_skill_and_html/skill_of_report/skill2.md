# 摘要字符串 → CET-4 听力 News Report Three

## 输入输出

- **输入**：一段英文 description 文本（约 150 词），由上游 Agent 整理爬虫数据后给出。**其中的英文叙述部分即唯一事实来源**，不假设存在标题、正文或任何其他字段。
- **输出**：**一个纯英文字符串**，只有新闻正文，直通 TTS。

## 执行步骤

1. **净化** —— 上游 Agent 可能夹带非正文内容，必须先剔除再使用：中文说明与对话（"好的，这是摘要"、"以下是整理结果"）、解释语、免责声明、Markdown 标记、`SOURCE:` 之类的字段名、代码块围栏。**只保留其中的英文叙述性句子**。净化后若不足以判断核心事件，如实说明无法生成，不得凭空创作。
2. **通读** —— 把净化后的文本当作新闻摘要读完。若过短（不足约 15 词）或残缺到无法判断核心事件，如实说明无法生成。
3. **清洗** —— 去除 HTML 标签；实体解码（`&amp;`→`&`、`&#39;`→`'`、`&quot;`→`"`）；删掉来源尾巴、订阅引导、`Read more` 等噪声；若末句被截断，只保留到最后一个完整句，残缺部分**丢弃，不得脑补**。
4. **抽骨架** —— 从清洗后文本提取 Who / What / When / Where / Why / How。缺项记为未知。
5. **扩写** —— 倒金字塔结构，可写 3 段：
   - 首句即核心事件；
   - 第二段补细节、引语或数据，**只能来自净化后的输入文本**；
   - 第三段收在结果、后续措施或展望上，可带一个 `however / but` 转折；词数不足时补**无实体指向的通用新闻表述**。
6. **校准** —— 按口径数字数，不达标就继续删或补，直到进入区间。
7. **输出** —— 只输出正文，一个字都不多。

## 目标词数（硬指标）

- **News Report Three：175 词，允许 ±5（即 170–180）。超出必须重写，宁可略少不可超。**

统计口径：空格分词；连字符词算 1 个；`1.5 million` 算 2 个；专名按空格分词；标点不计。

## 用词与句式

- 词汇限四级大纲（约 4500 词）。常用降级：`commence→begin`、`utilize→use`、`implement→carry out`、`significant→big/major`、`approximately→about`、`authorities→officials/police`、`casualties→the dead and the injured`、`surge→jump/rise sharply`、`plummet→fall sharply`、`nevertheless→but/however`、`subsequently→later`、`prior to→before`、`numerous→many`、`a majority of→most`。
- 被动改主动；定语从句拆成两句；每句 15–25 词，超过 25 词必拆。
- 时态：主体一般过去时，引语内可用现在时或将来时。
- **不得虚构人名、地名、机构名、数字、引语或因果关系**——输入文本里没有的一律不写。
- 每篇至少 1 个地名 + 1 个机构或人物名，数字 2–4 处，且全部取自输入文本。
- 体裁：这是收尾篇，篇幅最长，信息层次最多，末段要有收束感。

## 纯文本硬约束

**允许**：英文字母、阿拉伯数字、半角 `,` `.` `?` `!` `'` `-`、双引号（仅用于引语）、空格、换行。

**禁止**：

- 格局标记：`===`、`##`、`**`、行首 `-`、`1.` 序号
- 字段名：`SOURCE:` `TOPIC:` `WORD_COUNT:` `PASSAGE:` `SWAPS:` `FLAG:` 等
- 括号 `()` `[]`、斜杠 `/`、和号 `&`、省略号 `...`、`!!` 这类连续标点
- 缩写形式（`won't` 写成 `will not`）、`etc.` / `e.g.` / `i.e.`
- 中文及全角标点
- 任何文件路径、目录名、"参见/读取某文件"之类的提示
- 任何引导语（"以下是""改写如下""参考译文"）

**排版**：段落之间空一行；正文以第一个实词开头，以最后一个句号结束。

**数字可读化**：百分比写 `12 percent`；货币避免小数；时间不用 `15:30` 冒号写法；能取整就取整。
